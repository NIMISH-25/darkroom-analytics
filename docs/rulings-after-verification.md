# Rulings after the independent verification run

These decisions settle questions the first verification run raised. They are part of the frozen contracts (they refine `docs/db-contract-amendment-2.md` and `docs/api-contract-amendment-2.md`). Each is an assumed decision, not a customer answer.

1. **Unknown creator ids are unresolved, not resolved.** An attribution whose creator id is not on the brand's roster (or is not the id of a known creator) lands in the reconciliation bucket `creator_unresolved`, its amount stays visible in the totals, and the raw identifier is listed in `gold.unresolved_identity` and `/data-health`. Look-alike handles are never merged by similarity. Only creators known by id or by a reviewed alias count as `resolved`.
2. **Non-USD orders are excluded from USD GMV.** The original amount and currency are stored (`silver.shop_order.currency`). An order whose currency is not USD is not eligible, appears in the evidence exclusions with reason `non_usd_currency` (count and amount in the original currency, labelled), and raises a `currency_mismatch` quality issue. No conversion is attempted (the customer supplied no FX source).
3. **Concentration basis.** `creator_concentration` covers all months through the request cutoff (gross attributed GMV of eligible, resolved lines). It honours the `cutoff` parameter; the series `meta.basis` says "all months through <cutoff>".
4. **Retainer cadence prorates partial months.** For each of the trailing three complete months in which a contract is effective for any part of the month, the series emits a point with `expected_posts = posts_per_month x allocation share x (effective days in month / days in month)`. `posts` and `attainment_pct` are null unless the brand's weekly video coverage is gap-free through month end. A verified zero (full coverage, no posts) is `posts: 0` with `attainment_pct: 0.0`.
5. **Portfolio KPI values vs goal basis.** A portfolio KPI value (for example creator-attributed GMV) is the guarded sum of the brands' actuals (null if any brand's actual is unknown). Goals with mixed gross and net bases only affect `progress`, `baseline` and `delta`, which are null with a reason when the bases differ.
6. **Diagnostics periods.** The baseline period is the same calendar days of the previous month, using the same eligibility rules as the current period, and both are read from the same view. If either period's video or order coverage is incomplete the factor effects are null with the reason; the totals are still returned when their own sources are complete.
